# SS News

Original social + news website prototype.

## Included
- Responsive homepage
- News feed and categories
- Trending section
- Search
- Likes/reactions
- Comments demo
- Save/bookmark system
- Share button
- User profile area
- Create community post modal
- Newsletter signup demo
- Advertisement placements
- Dark/light mode
- Mobile navigation
- SEO-friendly basic metadata
- Demo admin dashboard
- Moderation/analytics UI
- Original design and assets-free implementation

## Run
Open `index.html` in a browser, or serve the folder with a local server:

`python -m http.server 8080`

Then visit `http://127.0.0.1:8080`

## Important
This is a front-end prototype. Real accounts, database storage, authentication, moderation, push notifications, analytics, ad networks, image uploads and production SEO infrastructure require a backend/services and deployment configuration.
